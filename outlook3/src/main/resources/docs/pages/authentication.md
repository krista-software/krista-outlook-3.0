# 🔐 Authentication

This section explains how authentication works in the Krista Outlook Extension, based on your configuration.

---

### ✅ Authentication via Service Account

- If you **uncheck** the **Have people authenticate with their account** checkbox, the **service account** will be used to execute the conversation.
- This is the **same account** that is configured and validated during the extension setup process.

![Service Account Authentication](../_media/askASystemUnchecked.png)

---

### 👤 Authentication via User Account

- If you **check** the **Have people authenticate with their account** checkbox, each user must **authenticate with their own account** while executing the conversation.

![User Account Authentication](../_media/askASystemChecked.png)
